# ✈️ VoyageR – Smart Travel Booking Platform

VoyageR is a full-stack MERN travel platform that enables users to explore destinations, book hotels, and connect with local guides, enhanced with immersive 360° panorama previews.

---

## 🎯 Key Features

* 🌍 Explore destinations with dynamic location data
* 🏨 Hotel search and booking system
* 🧑‍🤝‍🧑 Local guide connectivity
* 🔐 Role-based access (User, Guide, Admin)
* 🌀 360° panorama viewer for destination exploration
* ⚡ Fast and responsive UI

---

## 🧠 How It Works

1. Users browse destinations via integrated APIs
2. Search and book hotels based on location
3. Connect with verified local guides
4. Role-based system manages access and operations
5. 360° panorama viewer enhances destination exploration

---

## 🌐 Integrations

* Google Places API for real-time destination data
* Map-based insights for better travel planning
